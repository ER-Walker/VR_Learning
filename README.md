# VR_Learning
A series of simple VR learning applications from Unity Learn VR Developer course

## Purpose

This repository serves as central hub for exercises from the Unity VR Developer course found on Unity Learn. As such, none of the projects found in this repository are of my own personal creation, but rather my rendition of the provided materials.

I choose to use GitHub for this project in an attempt to see its viability in developing Unity projects, as well as practice in using proper version control practices and methodology.

## Branches

The main branch serves as the location of completed projects.  Works in progress should be located in a branch given their respective units and titles spaced by underscores (ex. Unit_1_VR_Basics).
